# AplicativoSaude_WindowsForms
O aplicativo de saúde foi criado para medir o IMC pessoal com base no peso e altura, e por fim calcular quanto de água a pessoa deve beber por dia em litros e convertê-los para copos de 240ml

## ✦ Sobre
Projeto pessoal realizado baseado no projeto de calculadora IMC proposto em sala de aula, na matéria de programação orientada a objetos(POO)

## ✦ Funcionalidades
- [x] Calcular IMC.
- [x] Fazer um relatório com a descrição do IMC, quantidade de água que a pessoa deve beber por dia em litros e qauntos copos(baseado em um copo de 240ml).
- [x] Botão de limpar visor.
- [x] Tratamento de erros para peso e altura inválidos.
